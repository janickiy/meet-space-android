# MeetSpace Android 0.4.3-beta · сборка 38

## Изменения

- Переработано окно управления участником конференции: компактная карточка с именем и ролью, действия с иконками, отдельное подтверждение удаления. На телефонах и планшетах поддерживаются обе темы; крупный шрифт сохраняет доступ к действиям через прокрутку.
- Убраны команды «Отключить микрофон», «Отключить камеру», «Отключить экран» и обратные команды разрешения. Android больше не отправляет эти действия из управления участником. Собственные устройства и действующие серверные ограничения не менялись.
- Смена роли и удаление доступны согласно правам текущего участника. До ответа сервера кнопки блокируются. Ошибка остаётся в окне для повторной попытки; удаление не закрывает его до подтверждённого изменения списка участников.
- Настройки уведомлений приведены к макету: приглашения и изменения встреч, напоминания, готовность записи, «Звуковой сигнал» и «Проверить звук», явное сохранение изменений. Скрытые параметры доставки сохраняются.
- Настройка звука отдельная для каждого аккаунта и сервера на устройстве. Учитываются системный канал, громкость уведомлений, беззвучный режим и «Не беспокоить». Предпрослушивание останавливается при уходе с экрана; ошибка сохранения событий не сбрасывает введённые настройки.

## Проверки

- Debug APK и Android test APK собраны. 576 JVM-тестов прошли, 12 opt-in тестов пропущены. Android Lint: 0 ошибок, 64 предупреждения.
- На финальном подписанном APK прошли 35 Android-проверок: 30 на планшете, 4 на смартфоне 390×844, 1 дополнительная проверка в окне 320×640 с масштабом шрифта 1,5. Проверены обе темы, длинные имена, доступность действий, роли, подтверждение удаления, ошибка и повтор, сохранение настроек уведомлений и системные ограничения звука.
- Проверена установка поверх опубликованной сборки 37 с сохранением контрольного файла в приватных данных и запуск приложения. Реальная авторизованная сессия для проверки обновления не использовалась.
- Подпись совместима с предыдущей beta, проверено выравнивание ZIP 16 KiB. Native-библиотеки и assets установщика не изменились.

[Результаты и скриншоты](evidence/beta-0.4.3-build-38/).

Проверки выполнены на отдельном эмуляторе API 36 ARM64. Физическое устройство, слышимость звука на устройстве и действия с реальными участниками production-конференции не проверялись. Проверки звука использовали Android Notification/Ringtone API; эмулятор запущен без вывода звука на компьютер.

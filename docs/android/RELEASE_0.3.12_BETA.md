# MeetSpace Android 0.3.12-beta

27 октября 2026 года. `versionName=0.3.12-beta`, `versionCode=30`. Android 8.0/API26 и новее.

## Изменения

- Центр уведомлений во встречах и чатах: счётчик, фильтры, чтение всех событий и переходы к материалам. Новые уведомления сопровождаются звуком при разрешённых системных настройках, включая открытое приложение.
- Общий каталог записей, отображение обложек и открытие материалов отдельных дорожек. Для общего каталога требуется поддерживающий его backend.
- Исправлены восемь ошибок аудита: своевременная остановка медиаресурсов, поздние ответы разрешений, очистка отозванных данных, отменённых экспортов, ложная потеря доступа к чату при ошибке дополнительного API, открытие материалов, восстановление громкости вызова и обработка больших резервных копий установщика.
- Добавлены регрессии и исправлена синхронизация тестов клавиатуры и управляемых полей. Подробности и исходные доказательства: [аудит](../audit/ANDROID_AUDIT_SUMMARY.md).

## Проверки

- После изменения версии собран debug APK;527 JVM-тестов прошли,12 opt-in live tests пропущены стандартным запуском. Lint:0 ошибок,57 предупреждений.
- В аудите отдельно прошли150 Python-проверок и9 opt-in API/WSS тестов; реальные сценарии Pion/SFU/TURN, MediaProjection, чатов, уведомлений, записей и SAF.
- UI:188 успешных случаев и8 opt-in пропусков по последним результатам нескольких прогонов. Единый повтор всех196 тестов после правок harness не выполнялся.
- Проверены подпись APK,16KiB ZIP alignment и побайтовое совпадение подписанных assets установщика.
- Проверка обновления опубликованного0.3.11-beta до0.3.12-beta и запуска выполнена отдельно на чистом API36 ARM64 эмуляторе; результат сохранён в evidence этого выпуска.

Физические устройства, полная установка backend на disposable VPS и background FCM в этом выпуске не проверены. FCM остаётся отключённым без отдельной Firebase-конфигурации. Полные ограничения — в отчёте аудита.

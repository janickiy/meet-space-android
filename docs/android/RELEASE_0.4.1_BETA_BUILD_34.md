# MeetSpace Android 0.4.1-beta · сборка 34

30 октября 2026 года. `versionName=0.4.1-beta`, `versionCode=34`.

## Изменения

- Редактор аватарок пользователя и группы адаптирован для планшета по предоставленному примеру: большое круглое превью слева, выбор/замена фото, масштаб, положение и сброс кадра справа. Две колонки сохраняются и до выбора изображения.
- «Отмена» и «Сохранить фото» закреплены внизу справа. Контент прокручивается отдельно, поэтому действия доступны при небольшой высоте окна.
- Убрана лишняя высота превью. На узком экране или при увеличенном шрифте используется одна колонка. Положение фотографии показывается в диапазоне 0–100%, центр — 50%; сама геометрия обрезки не изменена.
- Номер версии сохранён по запросу; внутренний код повышен с 33 до 34 для обновления поверх предыдущего APK. Сертификат beta-подписи сохранён.

## Проверки

- Debug APK и instrumentation APK собраны. 554 JVM-теста прошли, 12 opt-in проверок пропущены. Android Lint: 0 ошибок, 64 предупреждения приложения.
- На финальном подписанном APK прошли 14 UI-проверок на шести конфигурациях эмулятора: 1000×834, 834×1000, 600×800, 390×844, 844×390 и 1000×834 со шрифтом 1,6×. Проверены пустой редактор, выбор/замена фото, перетаскивание, ползунки, сброс, явное сохранение, отмена, ошибка сохранения и доступность нижних кнопок.
- Установка поверх опубликованной сборки 33 на API36 ARM64 прошла, контрольный файл в приватных данных приложения сохранился, запуск успешен. Реальные авторизованные аккаунты для этой проверки не использовались.
- Подпись и 16 KiB ZIP alignment проверены. Assets установщика и native-библиотеки совпадают с предыдущим опубликованным APK.

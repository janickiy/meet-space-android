# MeetSpace Android 0.3.9-beta

23 октября 2026 года. `versionName=0.3.9-beta`, `versionCode=27`.

Исправлена ошибка `IMAGE_BUILD_FAILED`: рецепт предыдущей версии передавал
`2026-10-22T20:41:14+03:00` в Docker `BUILD_TIME`, а сборка веб-интерфейса
принимает время только в UTC с суффиксом `Z`. Установщик теперь передаёт
эквивалентное время `2026-10-22T17:41:14Z`. Часовой пояс учитывается;
дата и время не подменяются текущими.

Нормализация выполняется перед операциями с образами и не изменяет
замороженные manifest/plan во время возобновления. Инструмент подписи
также нормализует дату до подписания нового рецепта. Невалидные даты,
отсутствующий часовой пояс и дробные секунды отклоняются до сборки.
Версия backend и закреплённый commit `a7d037ea9c228590bcd482d5eba410318029c4dd`
сохранены. Публичный ключ подписи установщика не менялся.

  переход даты, отказ для неверного времени, фактические аргументы Docker,
  неизменность manifest и проверку подписи.

  `:core:ssh:testDebugUnitTest`, `:app:lintDebug` завершились успешно.
- Android: 198 тестов приложения и 69 тестов SSH; ошибок и пропусков нет.

- Пять подписанных assets в APK побайтово совпадают с исходным bundle.
- APK подписан тем же сертификатом, что предыдущие локальные beta APK.

## Проверка на VPS

Прерванная установка была возобновлена с исходным подтверждённым планом
через одноразовый операторский обработчик, который нормализовал только
аргумент `BUILD_TIME` при сборке Docker. Исходный подписанный bundle,
plan hash и commit на VPS не заменялись. Установка достигла состояния
`completed`, прошла все десять стадий, включая миграции и readiness.

12 контейнеров MeetSpace работают; все 10 контейнеров с healthcheck имеют
статус `healthy`. Проверены HTTP 200 для главной страницы, `/version` и
`/version.json`, совпадение версий и коммитов, доверенный HTTPS, запрет
неавторизованного WebSocket, TURN TLS/авторизация/запрет приватных peers.
Таймер продления TLS включён. Страницы главной и входа открыты в браузере.
Шесть контейнеров Amnezia/VPN и семь файлов их конфигурации совпадают
с состоянием до восстановления. После установки свободно 11,62 ГиБ.

Эта проверка не подтверждает сквозной видеозвонок, запись, доставку SMTP
или повторную чистую установку именно с нового APK на физическом Android.

# MeetSpace Android 0.5.2-beta

Версия: `0.5.2-beta`, Android versionCode: `41`.

## Изменения

- В окне «О встрече» кнопки действий используют единую минимальную высоту 48 dp; длинные подписи при увеличенном шрифте могут переноситься.
- Иконки нижней навигации выровнены по центру, подписи «Встречи», «Чаты» и «Профиль» расположены на одной высоте на телефоне и планшете.
- «Профиль» показывает фотографию активного аккаунта. Она обновляется при изменении аватара и переключении пользователя; без фотографии отображаются инициалы.
- Аватар доступен также перед входом во встречу, во время звонка и в разделе записей. Старая фотография очищается перед загрузкой другого аккаунта или новой версии изображения.
- Проверки аватара и навигации включены в список тестов CI. README ссылается на новый пакет.

## Проверки

- Debug APK, androidTest APK и Android Lint собраны успешно, ошибок lint нет.
- 583 JVM-теста прошли, 18 проверок отдельных стендов пропущены без явного включения.
- На отдельном эмуляторе API 36 прошли 15 проверок без пропусков: реальные декодированные изображения в навигации, смена аккаунта, новая версия и удаление фотографии, выравнивание на телефоне/планшете, навигация встречи и записей, действия встречи с увеличенным шрифтом, изоляция и освобождение кеша аватаров.
- Подписанный APK установлен поверх 0.5.1-beta/build40. Маркер приватных данных и локальные параметры аудио сохранились; приложение запустилось. Миграция реального авторизованного профиля в этом прогоне не проверялась.
- Содержимое упакованных ресурсов установщика совпадает с исходниками. Все 12 нативных библиотек совпадают с предыдущим пакетом.

Результаты: `evidence/beta-0.5.2-build-41/`. Проверки интерфейса используют тестовые изображения и пользователей; вход в рабочий аккаунт и физическое Android-устройство в этом выпуске не проверялись.

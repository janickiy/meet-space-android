# MeetSpace Android 0.3.11-beta

23 октября 2026 года. `versionCode=29`, `versionName=0.3.11-beta`.

## Изменения

- Единое оформление поиска на главной, во встречах, чатах и записях: фокус, очистка и удобные области нажатия.
- Читаемые карточки записей и аккаунтов, адаптивные фильтры, формы с учётом ширины окна и размера шрифта.
- Кнопки добавления аккаунта отделены от полей; переключатели настроек доступны по нажатию на строку.
- Параметры установщика сгруппированы; оформление выбора способа установки и основных кнопок выровнено.
- Обновлена вёрстка управления папками и создания чата.
- Убраны кнопка «Материалы» из карточек завершённых встреч, подпись «Ваши пространства» и пояснение «Уведомления по почте / Приглашение отправляется сразу…».

## Проверки

- Debug APK и instrumentation APK собраны.
- 200 JVM-тестов приложения прошли.
- 108 функциональных UI-тестов на эмуляторе Android API 36 прошли. Тест расположения фильтров обновлён под перенос строки при крупном шрифте и повторно выполнен; остальные 107 прошли в общем запуске. Пять опциональных тестов снимков были пропущены в общем запуске.
- Отдельно прошли три теста снимков: встречи для телефона, большого телефона и планшета в двух темах, главная и форма добавления аккаунта. Просмотрены снимки интерфейса.
- Lint: 0 ошибок, 57 предупреждений. `git diff --check` без ошибок.
- APK установлен поверх предыдущего на эмуляторе; сертификат подписи совпадает. Assets установщика побайтово совпадают с подписанным пакетом.

Физическое устройство, реальные звонки и новая установка backend на VPS в этом выпуске не проверялись. Изменения относятся к интерфейсу Android.

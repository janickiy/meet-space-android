# MeetSpace Android 0.6.21

- Окно записи встречи обновлено по макету. На смартфоне варианты записи расположены в один столбец, на планшете — в два. Формат можно выбрать перед запуском записи.
- В настройках профиля добавлено многострочное поле «О себе» между именем и адресом электронной почты. На сервере с поддержкой этого поля можно сохранить или очистить текст длиной до 500 символов.

Сборка Android 66.

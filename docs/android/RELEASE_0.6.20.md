# MeetSpace Android 0.6.20

- Раздел «Записи встреч» обновлён по макету. На смартфоне записи отображаются списком, а фильтры периода и сортировки занимают равные колонки.
- На планшете можно переключаться между списком и плиткой. Плитка занимает две колонки в портретной и три в альбомной ориентации на размерах макета.
- Карточка открывает запись или её материалы. Удаление доступно по кнопке с корзиной и требует подтверждения.

Сборка Android 65.

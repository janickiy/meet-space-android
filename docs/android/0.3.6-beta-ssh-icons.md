# Android 0.3.6-beta

17 октября 2026 года. APK: `dist/MeetSpace-0.3.6-beta.apk`, versionCode 24.

## Изменения

После успешной SSH-проверки пароль или приватный ключ с passphrase передаются установщику без повторного ввода. Проверка использует отдельную копию, чтобы очистка её ресурсов не уничтожала доступ следующего шага. Передача одноразовая, связана с host/port/user, доменом и подтверждённым публичным ключом сервера. Установщик повторно проверяет pin перед SSH-аутентификацией.

Для IPv4-сервера план запрашивается сразу. Если указан hostname, уточняется только публичный IPv4; поле пароля и импорт ключа скрыты. Ожидающий передачи доступ и ожидание уточнения IPv4 ограничены десятью минутами. Во время активной установки данные остаются в RAM открытого мастера для наблюдения и управления. Отмена, завершение, ошибки и уход из мастера очищают доступ. В UI state, SavedState и на диск секреты не передаются. Установка по-прежнему требует явного подтверждения плана.

В окне «О встрече» кнопки получили иконки выхода, видеозвонка, копирования, приглашения, завершения и просмотра записей. Иконки также добавлены к регистрации, входу, началу, изменению расписания и отмене встречи. Сохранены подписи, цвета, состояния доступности и подтверждения опасных действий. Иконки не дублируют текст при озвучивании интерфейса.

Сборка включает предыдущее снижение исходящего микрофона на 20% и актуальный код приложения, дизайна и установщика. В Android-репозитории до этой публикации находились исходники 0.2.0; синхронизированы согласованные исходники, модели, installer и тесты. Краткий README без информации о версиях сохранён.

## Проверки

- Debug APK и test APK собраны; Android lint — без ошибок. Повторная сборка окончательного снимка подтвердила актуальность результатов.
- Unit: **456 успешных**, **12 пропущенных** проверок, требующих отдельного интеграционного стенда. Ошибок нет.
- На эмуляторе `MeetSpace_Tablet_API_36` выполнена 21 выбранная проверка: мастер SSH, форма установщика без повторного пароля, кнопки активной и запланированной встречи, native lifetime аудиодвижка. Все 21 проходят. В первом прогоне новый тест неоднозначно находил одинаковую подпись в фоне и диалоге; селектор ограничен конкретной кнопкой, повторная проверка прошла.
- Проверены одноразовая передача пароля/ключа, TTL, очистка, привязка к серверу/домену/pin, pending job, двойной тап и поздние ответы после отмены.
- Подпись APK проверена, сертификат совпадает с опубликованным APK 0.2.0-beta.
- Визуально проверен [скриншот](evidence/ssh-access-icons-036/meeting-actions.png) с тестовыми данными и увеличенным шрифтом.

Результаты и SHA-256: [evidence/ssh-access-icons-036](evidence/ssh-access-icons-036/).

Настоящая установка на VPS, физический Android и акустическая громкость в этом изменении не проверялись. Проверки UI выполнялись с фикстурами и callbacks; удалённый сервер не изменялся.

Веб-правки микрофона опубликованы отдельно в backend-репозитории: [f09529e](https://github.com/janickiy/meet-space/commit/f09529ea19dd6856c27d49448dceddc4e22cee96).

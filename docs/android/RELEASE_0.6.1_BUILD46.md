# MeetSpace Android 0.6.1 — сборка 46

Версия приложения: `0.6.1`, Android versionCode: `46`.

## Исправление установщика

На проверяемом VPS прежний подписанный установщик воспроизвёл HTTP `503`/`504` при запросе метаданных релизов GitHub. Сбой происходил во время подготовки плана, до загрузки Docker-образов. Он совпал по времени с [инцидентом GitHub «Increase in timeouts for some unauthenticated users»](https://www.githubstatus.com/incidents/pyynvrm1vskw), начавшимся 8 ноября 2026 года в 10:36 UTC / 13:36 МСК.

Для временных HTTP-ошибок и обрывов соединения добавлены максимум три попытки загрузки. Повтор выполняет новый запрос к тому же ресурсу с запретом использования кешированного ответа. Канонический URL в плане остаётся прежним. Для оборванного архива временный файл и SHA-256 начинаются заново; сохраняются общий срок загрузки, отмена и удаление неполных файлов.

Ошибки сертификата, запрещённого адреса, структуры JSON и контрольной суммы не обходятся. Готовый архив с неверным SHA-256 отклоняется сразу. Автоматического перехода к сборке из исходников нет. После исчерпания попыток для временного HTTP-сбоя отображается отдельное сообщение о временной недоступности сервиса.

## Автоматический выбор релиза

Поле ручного ввода `latest` удалено из мастера. Новые планы режима «Готовые образы» используют автоматический выбор последнего опубликованного совместимого релиза из [janickiy/meetspace_docker_built](https://github.com/janickiy/meetspace_docker_built/releases); значение `latest` задаётся также в ViewModel и запросе SSH-протокола.

После выбора план закрепляет конкретную версию, полный коммит бэкенда, URL, размер и SHA-256. Повтор загрузки не выбирает другой релиз. Для восстановления сохранённых заданий включён исходный подписанный набор установщика сборки 45.

## Проверки и ограничения

Прошли 170 Python-тестов: 150 существующих и 20 новых проверок транспорта. Они проверяют временные HTTP-ошибки, обрыв и укороченное чтение, запрет чужого redirect-host, ошибки TLS и JSON, ограничение количества попыток, отмену, общий срок загрузки, очистку временного файла, повторную проверку SHA-256 и отсутствие переключения на сборку из исходников.

Результаты: [evidence/release-0.6.1-build46](evidence/release-0.6.1-build46/). Пакет: `dist/MeetSpace-0.6.1.apk`.

Воспроизведение HTTP-сбоя и успешные автоматические проверки не подтверждают полную установку на VPS во время инцидента GitHub. Успешный сквозной запуск установки в этих условиях не заявляется. APK-проверки фиксируются отдельно после завершения сборки.

Пакет `dist/MeetSpace-0.6.1-build46.apk` собран в release-режиме и подписан прежним сертификатом. Прошли `assembleRelease`, `lintVitalRelease` и 117 Kotlin-тестов (83 `core:ssh`, 34 `InstallerViewModel`). Проверены подпись v2/v3, выравнивание 16 KiB и все 20 файлов текущего и исторических наборов установщика. UI-тест скомпилирован; запуска на Android-устройстве не было.

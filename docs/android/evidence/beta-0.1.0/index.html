Проверки

  • Сборка, проверка подписи и выравнивания APK прошли. Lint — без ошибок.
  • 334 unit-теста прошли; 12 opt-in проверок пропущены в обычном запуске. Отдельно прошли 3 проверки настоящего Android repository и 37 проверок REST-контракта.
  • Настоящий звонок между двумя Android-эмуляторами через Pion/TURN: 43 секунды, аудио и видео, входящий UserWS, переподключение, выключение и повторное включение камеры, история и освобождение медиаресурсов.
  • Проверки интерфейса телефона и планшета, регистрации после установки сервера, а также регрессии встреч и чатов прошли.
  • MediaProjection: 31 секунда первого показа, два поворота и повторный запуск с новым согласием. По приросту framesEncoded — 14,97–15,01 FPS при 49,38–59,50 входящих кадрах/с.

Границы проверки

Сетевые сценарии выполнены на изолированном экземпляре текущего backend. Физические устройства, Bluetooth, production-сервер, серверная запись и границы её сегментов в этом выпуске не проверялись. Снимки интерфейса сами по себе не подтверждают передачу медиа — её проверяли отдельно.

FCM пока не настроен: входящие вызовы доступны при активной сессии приложения. Вызовы при закрытом приложении и поверх экрана блокировки не реализованы. При уходе в фон микрофон и камера выключаются; после возврата их включает пользователь.

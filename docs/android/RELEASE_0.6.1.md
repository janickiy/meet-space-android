# MeetSpace Android 0.6.1

Версия приложения: `0.6.1`, Android versionCode: `45`.

## Установщик готовых Docker-образов

Режим «Готовые образы» получает пакеты из [janickiy/meetspace_docker_built](https://github.com/janickiy/meetspace_docker_built/releases). Параметр `latest` автоматически выбирает последний опубликованный совместимый релиз с пакетом для архитектуры сервера. Полные prerelease-сборки также участвуют в выборе; отдельный тег `latest` не требуется.

Источник пакетов указан в подписанном рецепте установщика. Исходники, происхождение образов и совместимость коммита проверяются по [janickiy/meet-space](https://github.com/janickiy/meet-space). План установки закрепляет конкретную версию, полный коммит бэкенда, URL, размер и SHA-256 архива. Запуск и продолжение используют этот план без повторного выбора `latest`.

Сохранены исходные подписанные наборы установщика для восстановления заданий `0.5.2-beta` и `0.6.0-beta`, сборка 43. Загрузка публичных пакетов не требует GitHub-токена в приложении или на VPS.

Первый перенесённый релиз: [`v0.6.1-prebuilt.20261108.4`](https://github.com/janickiy/meetspace_docker_built/releases/tag/v0.6.1-prebuilt.20261108.4), коммит бэкенда [`6dafb92e61827d14e8bc3745e48f5d01a1ef3cd6`](https://github.com/janickiy/meet-space/commit/6dafb92e61827d14e8bc3745e48f5d01a1ef3cd6). Архивы AMD64 и ARM64 перенесены без изменения байтов; внешние JSON-описания указывают на новый репозиторий.

В репозитории пакетов добавлен workflow сборки обеих архитектур из закреплённого коммита бэкенда. Он проверяет отчёты безопасности и публикует релиз после успешной проверки обеих архитектур. Проверка URL учитывает временный адрес черновика GitHub, затем требует адрес конкретной опубликованной версии.

## Проверки

- Release APK `0.6.1` (сборка 45) собран: `assembleRelease` и `lintVitalRelease` прошли. Проверены прежний сертификат подписи, схемы v2/v3, выравнивание 16 KiB и все 15 файлов текущего и исторических наборов установщика.

- Прошли 150 Python-тестов установщика, 80 JVM-тестов `core:ssh` и 8 тестов метаданных репозитория пакетов.
- Проверены RSA-подпись текущего рецепта, контрольная сумма сценария и сохранённый набор сборки 43. Все пять исторических файлов совпадают с прежним выпуском.
- Сохранённый план сборки 43 прошёл отдельную JVM-проверку восстановления без изменения содержимого.
- Реальный установщик без авторизации выбрал `latest` из нового репозитория для AMD64 и ARM64. Оба архива полностью скачаны; размеры и SHA-256 совпали с ранее проверенными пакетами.
- Проверки метаданных выполнены на настоящем черновике GitHub и на опубликованном релизе.

Результаты: [evidence/release-0.6.1](evidence/release-0.6.1/). Пакет: `dist/MeetSpace-0.6.1.apk`.

Новый workflow сборки Docker-пакетов целиком на GitHub в этой проверке не запускался. Использованы ранее собранные и проверенные архивы. Повторная установка на VPS и запуск этого выпуска на физическом Android-устройстве не выполнялись; серверы MeetSpace и Amnezia/VPN в рамках переноса пакетов не изменялись.

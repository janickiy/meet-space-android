# MeetSpace Android 0.6.15

- Обновлены карточки, фильтры и формы в разделе «Встречи» по макету для смартфонов и планшетов.
- Верхняя и нижняя панели используют единые размеры, отступы и контурные значки. В меню профиля отображается аватар текущего аккаунта.
- Меню действий в личных и групповых чатах оформлены по макету. На планшете из открытого диалога можно вернуться к списку чатов кнопкой в верхней панели.
- В видеовстрече плитки занимают больше места после поворота экрана. В режиме «Выступающий» лента участников выровнена с основной плиткой в портретной ориентации. Видео сохраняет исходные пропорции.

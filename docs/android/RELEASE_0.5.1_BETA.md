# MeetSpace Android 0.5.1-beta

Версия: `0.5.1-beta`, Android versionCode: `40`.

## Изменения

- Исправлены загрузка и сохранение настроек уведомлений с текущим API. Удалённое поле `summary` не требуется и не отправляется; на старых серверах его значение сохраняется. Флаги Email и push сохраняются при изменении категорий событий.
- Исправлен гостевой вход: актуальный сервер возвращает пустой email и роль `participant`. Проверка гостя остаётся привязана к пользователю и конференции; роли владельца/соведущего и гостевые права администратора отклоняются. Для обычного аккаунта email по-прежнему обязателен.
- В просмотре записи учитываются возможности сервера: скрываются удалённые расшифровки и ИИ-итоги, обращения к их адресам блокируются, включая переход из старого уведомления. Поддержка старых серверов сохранена.
- К действиям «Очистить историю» и «Удалить чат» добавлены иконки.
- Кнопки «Проверить» в настройках аудио занимают ширину содержимого вместо всей строки.
- README ссылается на актуальный APK.

## Проверки

- Сборка debug APK и androidTest APK, Android Lint: успешно, без ошибок lint; существующие предупреждения сохранены.
- 583 JVM-теста прошли, 18 проверок отдельных стендов пропущены без явного включения.
- На отдельном эмуляторе API 36: 69 UI/native-тестов прошли; 1 необязательный снимок чата пропущен. Проверены настройки, телефон/планшет/крупный шрифт, уведомления, чаты, записи, нативный WebRTC и обработка аудио.
- APK установлен поверх 0.5.0-beta/build39 с прежним ключом подписи. Маркер приватных данных и значения громкости/шумоподавления сохранились; приложение запустилось. Миграция реального авторизованного профиля в этом прогоне не проверялась.
- До сборки проверены 7 сценариев изменения данных на изолированном текущем Go API с PostgreSQL, Redis и S3: аккаунты, аватарки, группы, сообщения, файлы, папки, гости, личные звонки, управление записью и каталог. Проверка рабочего сервера после обновления API подтвердила HTTP 200 каталога на двух аккаунтах; их каталоги пусты.

Результаты выпуска: `evidence/beta-0.5.1-build-40/`. Подробная сверка API и проверка установленного сервера: `evidence/api-compatibility-2026-11-01/` и `evidence/api-deploy-2026-11-01/`.

Физическое Android-устройство, Bluetooth/USB-гарнитуры, акустика реального помещения и полный медиазвонок через рабочий SFU в этом выпуске не проверялись. Ранее выполненное измерение программного аудиотракта сохранено отдельно в `evidence/audio-runtime-0.5.0-build39/`.

## Известные ограничения

SSH-установщик не изменялся: адаптация подписанного пакета установщика к именам `record-worker` вместо `worker`/`live-worker` в новом backend остаётся отдельной задачей. API-проверки этого выпуска не подтверждают совместимость установщика с новым составом контейнеров.

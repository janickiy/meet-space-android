# MeetSpace Android 0.6.9

- В видеовстрече появились режимы «Сетка» и «Выступающий». На планшете сетка открывается по умолчанию и подстраивается под ширину окна и чата.
- Режим «Выступающий» автоматически показывает говорящего. Нажатие на плитку закрепляет участника, кнопка «Открепить» возвращает автоматический выбор.
- В плитках участников перечёркнутый микрофон показывает, что микрофон выключен.

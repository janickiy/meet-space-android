# MeetSpace Android 0.3.10-beta

23 октября 2026 года. `versionCode=28`, `versionName=0.3.10-beta`.

В установщике доступны два способа установки:

- **Готовые образы** — выбран по умолчанию для нового задания. Установщик
  находит последний опубликованный пакет для amd64/arm64, включая beta,
  либо использует явно указанный тег. Версия, полный коммит, архитектура,
  размер и SHA-256 пакета фиксируются до подтверждения установки.
- **Сборка на сервере** — прежняя сборка закреплённого исходного кода
  на VPS с ограничениями ресурсов компактного профиля. Текущий источник:
  `a7d037ea9c228590bcd482d5eba410318029c4dd`.

Поведение выбора пакетов сверено с `install.sh` и `scripts/install/from-images.py`
из backend commit `3ea9a4e83e82484c25402963b2e68a0642d986f6`.
Отсутствие готового пакета не запускает компиляцию автоматически. До запуска
можно изменить параметры, сохранив проверенный SSH-доступ открытого мастера.
После запуска режим, версия и пакет остаются закреплёнными при возобновлении.
Старые планы без `imageMode` трактуются как сборка из исходников; автоматическое
обновление ранее установленного backend или миграция чужого рецепта не добавлялись.

Проверяются размер и контрольные суммы архивов, безопасная распаковка,
OCI manifest/config digests, происхождение образов, архитектура, сканы и SBOM.
HIGH/CRITICAL блокируют загрузку. Сценарии из загруженного пакета не выполняются.
Для готовых образов на уже работающем Docker требуется Compose, Buildx не нужен.
Показаны отдельные этапы скачивания, проверки и импорта образов.

## Проверки

- 126 Python-тестов установщика: выбор выпусков и архитектуры, точный тег,
  фиксация плана, отсутствие автоматической сборки, сетевые ошибки,
  целостность, обход путей/ссылки, отмена, повторный импорт и старый режим сборки.
- 200 JVM-тестов приложения и 71 JVM-тест SSH: все прошли.
- 16 тестов `InstallerUiTest` на эмуляторе Android API 36: все прошли.
- Debug APK и instrumentation APK собраны; lint: 0 ошибок, 57 предупреждений.
- Проверены реальные опубликованные пакеты amd64 и arm64:
  `v0.4.0-prebuilt.20261023.2`, commit
  `577ec4f256bcb70c2b1bc83e7f6d1e3622dc3fad`.
- Новый этап загрузки выполнен на локальном Docker arm64: реальный
  `docker load`, фиксация 12 рабочих образов и отдельно Certbot, проверка
  происхождения. Повторный запуск не выполнял `load`, `pull` или `build`.
- В готовом образе frontend подтверждены ожидаемые версия и commit.
- Пять assets APK побайтово совпадают с подписанным пакетом установщика;
  сертификат APK тот же, что у предыдущих beta APK.

Работающий VPS и Amnezia/VPN в этой задаче не изменялись. Полная новая установка
с готовыми образами на чистом VPS, выпуск сертификата, звонки и SMTP через этот
новый режим не проверялись. Проверки импорта выполнялись локально, UI — на эмуляторе.

# MeetSpace Android 0.6.2

В мастере установки имя пользователя и пароль SSH вводятся вместе после проверки ключа сервера. В рамках открытого мастера те же данные используются для диагностики, получения плана, запуска и проверки статуса. Временный сетевой сбой можно повторить без ввода пароля. Если ответ на запуск потерялся, повтор сначала проверяет статус сохранённого задания.

Пароль остаётся только в памяти. Повторный ввод нужен при новом подключении после закрытия мастера, истечении срока доступа, изменении сервера или отклонении учётных данных. Вход по приватному ключу доступен на том же этапе.

Подписанный рецепт установки обновлён для [коммита бэкенда `6d91abb`](https://github.com/janickiy/meet-space/commit/6d91abb16a4914a441a9c5e5b5246f940bb4cbf4) с нумерованными миграциями. Сохранены прежние подписанные рецепты для восстановления уже начатых заданий. Готовые пакеты для AMD64 и ARM64 доступны в [релизе `v0.6.2-prebuilt.20261108.1`](https://github.com/janickiy/meetspace_docker_built/releases/tag/v0.6.2-prebuilt.20261108.1).

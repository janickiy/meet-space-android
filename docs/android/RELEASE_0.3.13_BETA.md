# MeetSpace Android 0.3.13-beta

30 октября 2026 года. `versionName=0.3.13-beta`, `versionCode=31`.

## Исправление входа

Обновлённый backend больше не возвращает пять флагов возможностей ИИ в `GET /api/v1/capabilities`. В Android эти поля были обязательными, поэтому успешный вход и проверка аккаунта завершались сообщением «Ответ сервера не соответствует API MeetSpace».

Отсутствующие необязательные флаги теперь принимают значение `false`. Явные значения старых серверов поддерживаются. Проверки токена, аккаунта, статуса ответа, типов полей и режимов записи сохранены. Исправление применяется и к первому входу, и к восстановлению сохранённой сессии.

## Проверки

- До исправления два регрессионных теста воспроизводили ошибку входа и восстановления; после исправления проходят.
- 531 JVM-тест прошёл, 12 opt-in тестов пропущены обычным запуском. Добавлены четыре проверки совместимости, включая отказ при некорректном API-ответе.
- Debug APK и instrumentation APK собраны. Android Lint: 0 ошибок; отчёт приложения содержит 57 предупреждений.
- Новый APK подписан прежним beta-ключом; проверены подпись, версия и 16 KiB ZIP alignment.
- Установка поверх опубликованной 0.3.12-beta прошла на API 36 ARM64 эмуляторе; контрольный файл в данных приложения сохранён.
- На chat.stage.org.ru проверен вход через интерфейс Android с предоставленной учётной записью и повторное создание Activity. В отдельном процессе подтверждены восстановление сохранённой сессии и её отзыв на сервере при выходе; оба live-теста прошли. Временный файл тестовых учётных данных удалён. Сервер: `20261030-eb18a39`, commit `eb18a390134d3bb88c0086fe00010228f0ffcc32`.

Первый live-прогон не прошёл из-за DNS эмулятора; следующий — из-за перекрытия кнопки системной клавиатурой в тесте. После настройки DNS и явного закрытия IME тест входа прошёл. TLS-проверки и сетевой код приложения не изменялись. Физическое устройство не использовалось.

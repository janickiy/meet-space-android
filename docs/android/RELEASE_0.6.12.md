# MeetSpace Android 0.6.12

- Обновлена вёрстка чатов для смартфонов и планшетов. Можно пересылать сообщения в другие чаты и удалять несколько выбранных сообщений за одно действие. Для пересылки нужна поддержка на сервере. Действие «Удалить у себя» скрывает сообщения на текущем устройстве.
- Вкладка «Аудио» и иконки в шапке раздела «Встречи» приведены к актуальным макетам.
- Переработаны экраны первого запуска и установки сервера, включая SSH, проверку VPS, выбор способа установки, план и ход установки.

Сборка Android 57.

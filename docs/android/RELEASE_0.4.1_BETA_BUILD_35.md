# MeetSpace Android 0.4.1-beta · сборка 35

30 октября 2026 года. `versionName=0.4.1-beta`, `versionCode=35`.

## Изменения

- Во встречах и личных звонках при вашей речи зеленеют фон кнопки микрофона, рамка и фон вашей карточки. Карточка собеседника подсвечивается, когда говорит он. Для видео добавлена лёгкая зелёная подложка; значок микрофона на карточке тоже подсвечивается.
- Активность определяется по уровням звука реального WebRTC, отдельно для локального микрофона и каждого принятого микрофона. Используется энергия новых аудиосэмплов за интервал, а не только последнее значение уровня. Звук демонстрации экрана не выдаётся за речь участника.
- Короткие паузы сглаживаются. Тишина, выключение микрофона, отключение участника и потеря связи снимают подсветку. Старые отчёты предыдущего подключения и устаревшие привязки дорожек игнорируются.
- Обновления статистики объединяются в очереди; одновременно запрашивается один общий отчёт. Уровень микрофона, обработка аудио и серверная конфигурация в этом изменении не менялись.
- Код сборки повышен с 34 до 35. Прежняя beta-подпись сохранена для установки поверх предыдущего APK.

## Проверки

- Debug APK и instrumentation APK собраны; 564 JVM-теста прошли, 12 opt-in проверок штатно пропущены. Android Lint: 0 ошибок, 64 предупреждения приложения.
- На финальном подписанном APK прошли 46 Android-проверок, 1 opt-in захват макета пропущен: 44 успешных проверки на планшете 1000×834 и 2 дополнительные проверки подсветки на телефоне 390×844.
- Синтетический тон и тишина прошли через настоящий закреплённый SDK: захват → Opus → локальное ICE/DTLS/SRTP-соединение → декодирование → рабочий детектор. Проверена идентификация локальной и принятой дорожек, включая streamless SDP. Микрофон пользователя для этого теста не использовался.
- Проверены состояния речи, тишины, одновременной речи, выключенного микрофона, переподключения, доступность кнопок и фактический зелёный цвет интерфейса. Существующие проверки экранов звонка и владельца аудиопроцессора также прошли.
- Установка поверх опубликованной сборки 34 на API36 ARM64 прошла. Контрольный файл в приватных данных сохранился, включая проверки после native-тестов; стартовый интерфейс открылся. Реальные авторизованные аккаунты для этой проверки не использовались.
- Подпись и 16 KiB ZIP alignment проверены. Assets установщика и native-библиотеки совпадают со сборкой 34.

[Результаты и скриншоты](evidence/beta-0.4.1-build-35/).

Физическое устройство и звонок через production SFU в этом этапе не проверялись. Native-аудиотест использует два настоящих WebRTC-подключения внутри эмулятора.

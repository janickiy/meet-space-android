# MeetSpace Android 0.4.1-beta

30 октября 2026 года. `versionName=0.4.1-beta`, `versionCode=33`.

## Изменения

- Из аудионастроек удалена строка шумоподавления.
- В профиле можно добавить, заменить или удалить аватарку пользователя. Фото отображается в профиле и карточке текущего аккаунта.
- В редакторе группы можно добавить, заменить или удалить аватарку. Управлять фото могут владелец и администратор; оно отображается в списке чатов и шапке разговора.
- Редактор фото повторяет макет: отдельное окно выбора, круглая область обрезки, перетаскивание, масштаб 100–300%, смещение по горизонтали и вертикали, сброс, предпросмотр и замена файла. Отмена сохраняет текущее фото, удаление требует подтверждения. Ошибка upload оставляет редактор открытым для повтора; окно закрывается после подтверждения сервера. Исходник и crop сохраняются в ограниченном RAM-кэше для повторного редактирования в текущем процессе, состояние редактора переживает смену конфигурации.
- Фотографии выбираются системным PhotoPicker без разрешения на всё хранилище. В редакторе разрешены JPG/PNG/WebP до 8 МиБ и 40 Мп; экспорт — квадратный JPEG512 без растягивания и метаданных. Перед отправкой учитывается поворот, изображение уменьшается, метаданные удаляются. Кэш изображений ограничен и изолирован по серверу/аккаунту.
- Исходящие сообщения чатов и комментарии встречи появляются локально сразу. При ошибке отправки у сообщения появляется красный восклицательный знак; баннеры, всплывающие сообщения и звуковые уведомления об этой ошибке не создаются. Через значок можно повторить отправку или удалить локальную запись. Можно продолжать писать следующие сообщения.
- Неотправленные сообщения сохраняются с шифрованием Android Keystore в каталоге, исключённом из резервных копий. После перезапуска они восстанавливаются для того же аккаунта и разговора. Повтор сохраняет идентификатор запроса; подтверждения сервера заменяют локальную строку без дубликата. Обычная смена аккаунта и выход не удаляют эти локальные записи; доступ к ним возвращается после авторизации в том же сохранённом профиле.

## Проверки

- Debug APK и instrumentation APK собраны; 554 JVM-тестов прошли, 12 opt-in live-тестов пропущены штатным запуском.
- Android Lint: 0 ошибок, 64 предупреждений в отчёте приложения.
- Проверены прежняя beta-подпись, версия, 16 KiB ZIP alignment и идентичность assets установщика предыдущей версии.
- Установка поверх 0.3.13-beta на API36 ARM64 эмуляторе сохранила контрольный файл в данных приложения.

Функциональная проверка редактора и остальных изменений выполнена на предварительной локальной сборке **0.4.0-beta**: 28 Android-проверок прошли, 3 аппаратных opt-in проверки пропущены; дополнительно прошли 3 проверки layout на иных реальных размерах эмулятора. Проверены 320×560, 390×844, 1000×834 и 844×390. Отчёт и исходный SHA сохранены без переименования в [исторической evidence 0.4.0](evidence/beta-0.4.0/android-tests.json).

Для публикации номер изменён на **0.4.1-beta** (`versionCode=33`), выполнены повторная сборка, 554 JVM-проверки и lint. Полный native suite на 0.4.1 повторно не запускался; версия, запуск и установка поверх 0.4.0-beta с сохранением данных проверены отдельно в [evidence текущего выпуска](evidence/beta-0.4.1/).

Физическое устройство и загрузка фото на production-сервер в этом этапе не использовались. API аватарок сверено с backend commit `ec4c6cd07a0569823248b5e29a5a5d75a31bb290` и проверено HTTPS mock-server тестами. Существующие записи, камеры, обработка звука WebRTC и серверная конфигурация не изменялись.

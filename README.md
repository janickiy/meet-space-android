# MeetSpace Android

Нативное Android-приложение для MeetSpace на Kotlin, Jetpack Compose и Material 3. Интерфейс адаптируется к телефонам и планшетам, поддерживает светлую и тёмную темы.

Приложение включает авторизацию и регистрацию, встречи и календарь, личные и групповые чаты, видеозвонки, демонстрацию экрана, записи встреч и настройки профиля.

## Установка

[Скачать APK](dist/MeetSpace-0.4.1-beta.apk) · [SHA-256](dist/MeetSpace-0.4.1-beta.apk.sha256)

В мастере установки сервера добавлены необязательные настройки SMTP. Их можно пропустить: установка продолжится без отправки писем, а почту можно подключить позже через [файлы конфигурации сервера](installer/README.md#enable-email-later-after-skipping-smtp). При настроенной почте приглашение отправляется сразу, напоминание — за три часа до запланированной встречи. Сборка на VPS использует сохраняемые кэши и продолжает уже завершённые этапы после проверки образов.

## Сборка

Нужны JDK 17 и установленный Android SDK. Укажите путь к SDK через `ANDROID_HOME` или в локальном `local.properties`:

```properties
sdk.dir=/путь/к/Android/Sdk
```

Собрать debug APK:

```sh
./gradlew :app:assembleDebug
```

Запустить основные проверки:

```sh
./gradlew :core:data:testDebugUnitTest :core:ssh:testDebugUnitTest :core:media:testDebugUnitTest :app:testDebugUnitTest :app:lintDebug
```

APK появится в `app/build/outputs/apk/debug/`. Готовый APK также доступен в папке [`dist`](dist/).

## Подключение

При первом запуске укажите корневой HTTPS-адрес сервера MeetSpace. Адрес сервера и учётные данные не вшиты в приложение.

## Структура проекта

- `app` — интерфейс, навигация и интеграционные тесты.
- `core:data` — API, хранение сессии и работа с данными.
- `core:designsystem` — тема и компоненты интерфейса.
- `core:media` — WebRTC, аудио, видео и демонстрация экрана.
- `core:model` — модели и состояния приложения.
- `core:ssh` — SSH-подключение и мастер установки сервера.

Подробная архитектура, настройки подписи, приватности и проверки находятся в [`docs/android`](docs/android/). Материалы по тестовому стенду и CI — в [`testing`](testing/).
